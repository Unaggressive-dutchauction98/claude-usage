## 🔎 What claude-usage does

claude-usage shows your Claude rate limits while you work.

It can show:
- Your current session usage
- Your weekly usage
- Reset timers
- A quick readout from a single API call
- Statusline-style output for fast checks

It reads your OAuth token from the macOS Keychain on Mac, then makes a small API call and shows your limit state. On Windows, the app is packaged as a single binary so you can run it without extra setup.
